🔗 API Endpoints

Update Profile:

PUT http://localhost:8080/profile

Headers: Authorization: Bearer {your_token}

Get Profile:

GET http://localhost:8080/profile

Headers: Authorization: Bearer {your_token}

Form Data Fields:

  • first_name - String (required, max 255)
  • middle_name - String (optional, max 255)
  • last_name - String (required, max 255)
  • email - Email (required, unique)
  • dob - Date (required, YYYY-MM-DD)
  • address - String (required)
  • description - String (optional)
  • children - Integer (optional, min 0)
  • profile_picture - File (optional, max 2MB)
  • profile_image - File (optional, max 2MB)
  • parent_email - Email (required if under 16)
